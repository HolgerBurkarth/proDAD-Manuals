# proDAD User Manuals

Central collection of the PDF user manuals for **proDAD** products in all available languages.

**proDAD GmbH** is a German software company (founded 1990) specializing in video effects and production software for filmmakers, content creators and ambitious amateurs.

**Editions**

- **SAL** – Stand-alone application (Windows)
- **Plugin** – Plugin for NLE host applications such as *Adobe Premiere Pro*, *Grass Valley EDIUS*, *MAGIX Video deluxe / Video Pro X*, *Boris FX VEGAS*, *Corel VideoStudio*, *DaVinci Resolve* and others

Most products are available as both SAL and plugin; the manual covers both unless stated otherwise.
